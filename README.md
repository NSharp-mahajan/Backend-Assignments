### 2. Student Management System — Array Methods Assignment
Located in: [`./Student-Management-System/`](file:///C:/Users/hp/Documents/Assignment-Backend/Student-Management-System/index.html)

A clean, beginner-level single-page web application engineered specifically for a college assignment. It visualizes student records inside a clean HTML table with white card layouts on a subtle `#F4F6F8` background using Royal Blue (`#2563EB`) buttons and Google's *Poppins* font.

#### ✨ Core Architectural Highlights:
- **No Show-Off, Clean UI:** Designed without distracting animations, glassmorphism, or heavy gradients. Prioritizes readability, simplicity, and standard academic submission standards.
- **Interactive Button Grid:** Features 13 distinct labeled buttons executing specific JavaScript array operations on click.
- **Live Output Section & Auto-Updating Table:** Whenever an array-mutating method (`push`, `pop`, `unshift`, `shift`, `splice`, `sort`) is executed, the main student data table updates instantly while displaying clear status alerts (e.g., *"Student Added Successfully"*) in the output box.
- **Modular Code Design:** Zero code repetition with standalone reusable helpers (`renderTable`, `formatAsTable`, `showOutput`) and cleanly commented individual function handlers for each task.

#### 📊 Implemented Operations:
1. `addStudent()` — Add Simran (ID: 106) using `push()`.
2. `removeLastStudent()` — Remove trailing record using `pop()`.
3. `addStudentBeginning()` — Prepend Ankit (ID: 100) using `unshift()`.
4. `removeFirstStudent()` — Extract first student using `shift()`.
5. `updateStudent()` — Locate ID 103 and replace with Karan (ID: 107) using `splice()`.
6. `showFirstThree()` — Extract non-mutative sub-array using `slice()`.
7. `displayStudents()` — Format records (`Name - Course - Marks`) using `for...of`.
8. `showNames()` — Iterate and output student names using `forEach()`.
9. `getStudentNames()` — Create new array of names using `map()`.
10. `filterHighScorers()` — Isolate high achievers scoring marks $\ge$ 80 using `filter()`.
11. `calculateTotalAverage()` — Compute total aggregate marks and mathematical average using `reduce()`.
12. `sortAscending()` — Arrange records from lowest to highest marks using `sort()`.
13. `sortDescending()` — Arrange records from highest to lowest marks using `sort()`.

#### 🛠️ How to Run:
Navigate into `Student-Management-System/` and open `index.html` in any desktop or mobile web browser.

### 3. Student Feedback Form
Located in: [`./Student-Feedback-form/`](file:///C:/Users/hp/Documents/Assignment-Backend/Student-Feedback-form/index.html)

A simple and practical feedback submission app where students can enter their name, email, selected course, and feedback. The form includes validation checks, saves the data in the browser using `localStorage`, and displays the current session user with `sessionStorage`.

#### ✨ Core Features:
- **Client-Side Input Validation:** Displays clear error messages for missing or invalid user input.
- **Persistent Data Storage:** Stores feedback details locally in the browser for later viewing.
- **Session Tracking:** Keeps track of the current session user after successful submission.
- **Delete Stored Data:** Allows the user to clear the saved feedback and session information.

#### 🛠️ How to Run:
Navigate into `Student-Feedback-form/` and open `index.html` in any desktop or mobile web browser.
